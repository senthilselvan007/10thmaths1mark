PWA package - 10th Maths 1 Mark Chapter Quiz

Files: index.html, manifest.json, sw.js, icons/ (4 PNGs)

How to use:
1. Upload ALL files (keep the icons folder) to one folder on any HTTPS host
   (GitHub Pages, Netlify, Cloudflare Pages, school server with HTTPS).
2. Open the link in Chrome/Edge on Android or desktop -> tap "Install App".
   On iPhone/iPad: Share -> Add to Home Screen.
3. It then works offline.

Note: a PWA does not install from a local file or from WhatsApp - it must be opened from an https:// link.
When you upload a new index.html, change CACHE name in sw.js (v2 -> v3) so phones update.
